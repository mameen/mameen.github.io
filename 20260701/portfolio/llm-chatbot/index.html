LLM Chatbot

Based on OSS Chatbot UI, I worked with the team to develop and deploy an internal version. It is a full-stack Next.js application. I added many features like image creation using DALL-E-3, and support for more LLM models like Claude 2.0 using AWS/Bedrock. I also added an API Swagger layer enabling several teams to easily access the LLM as a platform. I implemented the function interface in an extensible way to support user-implemented functions, and built an AI Assistant for benefits enrollment.
